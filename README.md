# وب‌سایت جواهری قسمتی

## صفحه‌ها
| فایل | صفحه |
|---|---|
| `index.html` | صفحه اصلی: انگشتر طلای سه‌بعدی، کلکسیون‌ها، تازه‌ها، طلای دست دوم، ساعت کاری |
| `collection.html` | همه کالاها با فیلتر دسته (`collection.html?c=ring` فقط انگشترها را نشان می‌دهد) |
| `product.html` | صفحه هر کالا (خودکار ساخته می‌شود: `?p=0` اولین کالای ویترین، `?u=0` اولین کالای دست دوم) |
| `secondhand.html` | گالری طلای دست دوم |
| `about.html` | درباره ما و تماس |

## عوض کردن اطلاعات و کالاها
فقط فایل `data.js` را ویرایش کنید. همه صفحه‌ها از همین فایل خوانده می‌شوند.

اختیاری برای هر کالا (در `PRODUCTS` یا `USED`):
```js
{ name: '...', ..., image: 'images/products/p01.jpg',
  images: ['images/products/p01.jpg', 'images/products/p01-b.jpg'],   // چند عکس در صفحه کالا
  description: 'یک یا دو جمله درباره این قطعه' }
```

## عکس‌ها
| کجا | فایل | اندازه پیشنهادی |
|---|---|---|
| کالاها | `images/products/p01.jpg` … | ۸۰۰×۱۰۰۰ عمودی |
| دست دوم | `images/used/u01.jpg` … | ۸۰۰×۱۰۰۰ عمودی |
| عکس بخش «هر قطعه را از نزدیک ببینید» و صفحه درباره ما | `images/editorial/craft.jpg` | ۱۲۰۰×۱۵۰۰ |
| عکس بخش «به ما سر بزنید» (مثلاً ویترین مغازه) | `images/editorial/store.jpg` | ۱۶۰۰×۱۰۰۰ |
| بالای صفحه دست دوم | `images/editorial/used-banner.jpg` | ۱۶۰۰×۹۰۰ |
| لوگو | `images/logo.png` | مربع، حداقل ۴۰۰×۴۰۰ |

عکس را با **همان اسم** جایگزین کنید. حجم هر عکس را زیر ۳۰۰ کیلوبایت نگه دارید.

## انگشتر سه‌بعدی
در `assets/js/ring3d.js` ساخته می‌شود (three.js، داخل پوشه `assets/vendor`، بدون نیاز به اینترنت).
روی دستگاه‌هایی که سه‌بعدی را پشتیبانی نمی‌کنند، به‌جایش عکس `images/products/p06.jpg` نشان داده می‌شود.

## فایل‌های قدیمی
`old-green.html`، `index-light.html` و پوشه `fonts` مال طرح قبلی هستند و در سایت جدید استفاده نمی‌شوند؛ اگر نخواستید پاکشان کنید.
