# وب‌سایت جواهری قسمتی

## دیدن سایت
روی `index.html` دوبار کلیک کنید تا در مرورگر باز شود. اینترنت لازم نیست؛ فونت‌ها داخل پوشه `fonts` هستند.

## عوض کردن اطلاعات و کالاها
فقط فایل `data.js` را (با VS Code یا Notepad) باز کنید. توضیح هر بخش داخل خود فایل نوشته شده:
- `SITE`: نام، نشانی، تلفن، ساعت کاری، اینستاگرام، متن «درباره ما»، لوگو
- `CATEGORIES`: دسته‌ها (همان هایلایت‌های اینستاگرام)
- `PRODUCTS`: ویترین کالاهای نو
- `USED`: گالری طلای دست دوم (`sold: true` یعنی فروخته شد)

## عوض کردن عکس‌ها
همه عکس‌های فعلی «تصویر نمونه» هستند. ساده‌ترین راه: عکس خودتان را با **همان اسم** جایگزین کنید.

| عکس | پوشه | اندازه پیشنهادی |
|---|---|---|
| عکس اصلی بالای صفحه | `images/hero.jpg` | ۱۰۰۰×۱۳۰۰ (عمودی) |
| ویترین | `images/products/p01.jpg` … | ۸۰۰×۱۰۰۰ (عمودی) |
| دست دوم | `images/used/u01.jpg` … | ۸۰۰×۸۰۰ (مربع) |
| لوگو (اختیاری) | `images/logo.png` و در data.js بنویسید `logo: 'images/logo.png'` | مربع |

عکس‌ها در قاب طاق‌نما بریده می‌شوند؛ جواهر را وسط عکس بگذارید.
پیش از گذاشتن، حجم هر عکس را زیر ۳۰۰ کیلوبایت نگه دارید تا سایت سریع باز شود.

## انتشار روی اینترنت
کل این پوشه یک سایت ساده (static) است و روی هر هاستی کار می‌کند.
برای دسترسی خوب از داخل ایران، یک هاست ایرانی (مثلاً سرویس‌های static/CDN داخلی) و یک دامنه `.ir` مناسب‌تر است.
